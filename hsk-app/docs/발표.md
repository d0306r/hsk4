# HSK 3·4급 단어앱 — 발표 준비

> 배포: https://hsk4voca.vercel.app · 시연 전 `/dev/seed`에서 "데모 데이터 생성"(게스트/로그아웃 권장)

---

## 1. 한 줄 소개
> "HSK 3·4급 필수 1,203단어를, **예문·발음과 함께** 매일 조금씩 외우고
> **틀린 단어는 복습(SRS)으로** 오래 기억하게 해 주는 웹앱(PWA)입니다."

---

## 2. 문제의식 (왜 만들었나)
- 기존 단어장 앱: **뜻만 암기** → 실제 문장에서 못 씀, 며칠 뒤 다 잊음
- 그래서 세 가지에 집중:
  1. **문장으로** 익히기 → 전 단어 예문 100%
  2. **잊을 때쯤 다시** 보기 → 간격 반복(SRS)
  3. **꾸준함**을 시각화 → 통계·연속 기록·목표·배지

---

## 3. 시연 동선 (이 순서로 클릭)
1. **첫 실행 온보딩** — (게스트/시크릿창) 4장 슬라이드로 앱 소개
   - *"처음 켜면 이렇게 안내됩니다"* (다시보기: 콘솔 `localStorage.removeItem('hsk-onboarded')`)
2. **홈** — 오늘 목표 링 · 전체 진도 · 급수별 학습/복습 대기 수
3. **학습(4급 시작)** — 섞기 모드: 한자→뜻 / 뜻→한자 / **빈칸 채우기** / **듣기(발음 자동재생)**
   - 정답/오답 시 **진동·애니메이션**(효과음은 설정에서 켜기)
   - 답 맞힌 뒤 **예문·발음 🔊** 노출
4. **학습 완료 화면** — 정답률, 틀린 단어(별표·발음), *홈 복귀 시 수치 즉시 반영*
5. **통계 탭** — 주간 리포트 · 정답률 추이 · **학습 잔디** · 자주 틀린 단어
   - **학습 인사이트**: "취약 품사/급수" · **성취 배지** 그리드
6. **약점 집중 복습** — 통계의 "🎯 집중 복습" → 틀린 단어만 모아 복습
7. **오답노트 / 단어장** — 검색·필터, 예문 포함 상세
8. **PWA** — "홈 화면에 추가" 설치 → 앱처럼 전체화면 → **비행기모드로 오프라인 시연**
9. **동기화** — 로그인 → 다른 기기/새로고침에도 진도 유지 (설정에서 백업 내보내기도)

## 4. 기술 스택 & 아키텍처 (물으면)
- **Next.js 14 (App Router)** + React + TypeScript
- **Tailwind CSS** — 라이트/다크 테마, 뉴트럴+인디고 포인트
- **zustand (+persist)** — 설정/학습/즐겨찾기/테마 상태
- **Supabase** — 인증 + Postgres(진도/세션/오답), RLS 적용
- **PWA** — manifest + 수동 서비스워커(오프라인 캐시), 설치 유도
- **핵심 설계 "옵션 A"**: **localStorage가 마스터**, DB는 백업/동기화용 → **로그인 없이도(게스트) 완전 동작**, 네트워크 실패에도 학습이 안 멈춤
- **SRS**: SM-2 기반 단순화(정답 시 간격 1→6→×ease, 오답 시 리셋)

## 5. 차별점 (강조 포인트)
- 예문·발음·뜻풀이 **전수 검수**(멀티 에이전트로 1,203개 점검·교정)
- **게스트 우선** — 설치·가입 없이 바로 학습, 필요하면 로그인해 동기화
- **오프라인 지원** — 지하철·비행기에서도 학습
- 학습 **동기 설계** — 목표 링·연속 기록·배지·취약점 인사이트

## 6. 2주간 개발 스토리 (물으면)
- 초기: 단어 데이터 + 기본 퀴즈 → 이후 SRS·통계·오답노트
- 디자인 정리(아이콘/팔레트), 기기 간 동기화 이슈 해결
- 예문 100% 보강 + 품질·뜻풀이 전수 검수
- 발표 대비: 게스트 모드·온보딩·오프라인·빈칸/듣기 퀴즈·약점복습·목표/배지·피드백·백업·에러 안전망

## 7. 예상 Q&A
- **Q. 데이터는 어디 저장?** A. 기본은 브라우저(localStorage), 로그인하면 Supabase에 백업·동기화.
- **Q. 오프라인이 왜 되나?** A. 서비스워커가 앱 셸/자원을 캐시. HTML은 네트워크 우선이라 배포 최신도 반영.
- **Q. 단어는 어떻게 뽑았나?** A. HSK 3·4급 공식 어휘 1,203개, 예문·발음·뜻 검수.
- **Q. 복습 주기 근거?** A. SM-2(간격 반복) 단순화 버전, 정답이 쌓일수록 간격이 지수적으로 증가.
- **Q. 앞으로?** A. 듣기 문장 문제 확장, 학습 리마인더 알림, 주제별 세트 등.
